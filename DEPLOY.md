# Deploying to Render (Free)

## One-time setup

1. Push this repo to GitHub (if not already there)
2. Go to https://render.com and sign up free
3. Click **New → Blueprint** and connect your GitHub repo
   - Render reads `render.yaml` automatically
4. Set these environment variables in the Render dashboard:
   - `GMAIL_ADDRESS` — your Gmail address (for future email features)
   - `GMAIL_APP_PASSWORD` — your Gmail App Password
   - `APP_BASE_URL` — your Render URL e.g. `https://your-app.onrender.com`
5. Click **Deploy**

## Notes
- Free tier spins down after 15 min of no traffic — first load after idle takes ~30s
- Scheduler is disabled (`ENABLE_SCHEDULER=0`) — email digests won't run
- `SECRET_KEY` is auto-generated by Render — no action needed
- Postgres is provisioned automatically from `render.yaml`
